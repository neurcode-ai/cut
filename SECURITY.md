# Security policy

Do not open public issues for suspected vulnerabilities or exposed secrets.
Report them to `security@neurcode.com` with the affected package and version,
reproduction steps, and impact. Do not include real Share payloads, access
links, credentials, or personal data.

Maintainers will acknowledge a report within three business days and coordinate
validation, remediation, and disclosure. Supported versions are the latest
minor release of each `0.x` package until a stable support window is announced.

The public repository covers the format, CLI, viewer, and SDK. Hosted-service
incidents should identify `share.neurcode.com` but must still omit access
secrets.
