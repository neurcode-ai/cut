# Cut by Neurcode

**The universal link for code.** Turn exact code, diffs, notes, and test output
into one focused Cut for teammates and AI agents.

```sh
npx @neurcode-ai/cut@0.5.0
```

After installing it, the memorable team workflow is:

```sh
cut teams
cut src/queue.ts --to backend --yes
```

This package is the stable product entry point for the open-source Cut CLI. It
uses the compatible `@neurcode-ai/share` engine underneath so existing installs,
archives, scripts, and integrations continue to work.

Learn more at [cut.neurcode.com](https://cut.neurcode.com).
